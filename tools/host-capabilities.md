# Agent 宿主能力参考

本 kit 把会话中使用过的能力整理成可替换的接口。`exec_command`、`view_image` 等名字是
本次宿主的工具名示例，不是必须安装的 Python 包，也不是所有 Codex/agent 都有的固定 API。
先查看当前会话实际开放的工具，再选择下表中的等价能力。

**Clone 仓库会得到工作流、源码和模板，不会附赠图像额度、模型订阅、SDK 许可、浏览器权限或 MCP 连接。**
不需要把所有宿主能力装齐才能开始；文件检查和最小导出可以先独立完成。

## 实际用过的能力与替代方式

| 能力 / 本次工具名示例 | 本次怎么用 | 其他 agent 可采用的替代方式 | 应留下的证据 |
| --- | --- | --- | --- |
| 命令执行：`exec_command`，长任务输出读取 `write_stdin` | 运行 Java/Gradle、Python、NCNN、Git 和验证脚本；读取退出码 | 受控终端、IDE shell、宿主进程工具 | 命令参数、版本、退出码、输出目录；日志中的私人路径发布前整理 |
| 文件定位与读取：shell、`rg` / `rg --files` | 找到 manifest、实现、图集、脚本与报告；按范围读取 | IDE 文本搜索、文件系统 API；没有 `rg` 时使用本机等价搜索 | 具体文件与行号，不凭文件名猜实现 |
| 文件修改：`apply_patch` | 修改遮罩配方、导出器、Web 预览与文档 | IDE patch、受控文件写入、Git diff | 变更差异、修改前后指纹、回归结果 |
| 图片查看：`view_image` | 阅读原参考、单层 RGBA、局部放大和动作截图 | 能真正读取图片像素的视觉工具、图像查看器 | 实际查看的文件及其参数状态；区分透明 RGB 与可见 alpha |
| 图像生成 / 编辑：`image_gen` | 正面立绘重绘与隐藏区域素材补全 | 当前宿主可用的图像工具，或用户绘画软件与已有素材 | 使用的参考、提示词、输出来源、用户批准的版本；后期固定获批脸 |
| 网络资料：`web` | 查阅 psd2live、官方 Simple Model、SDK、超分与可选 MCP 的原始说明 | 浏览器、联网文档检索、官方仓库读取 | 原始链接、固定 commit / 版本、查阅日期；区分现行接口和历史基线 |
| 浏览器交互：CUA / in-app browser | 打开实际预览、查看截图、操作参数与页面 | 当前宿主浏览器自动化工具，或手动浏览器操作 | 实际页面 URL、加载的模型身份、可见结果；不能只读 DOM 后宣称美术通过 |
| 可重复浏览器测试：Playwright | 在真实 Core/WebGL 页面检查输入、播放/暂停、布局和资源响应 | 本仓库 [`check-preview.cjs`](../scripts/check-preview.cjs)；或实现同等证据的浏览器测试 | 真实加载响应的 SHA、Core 版本、参数对 drawable 的影响、截图和错误 |
| 多 agent 协作：`spawn_agent` / 消息工具 | 拆分源图审查、工具审查、几何诊断与文档工作 | 宿主子代理；没有时顺序执行同一检查清单 | 每个子任务的文件归属、输入版本、结论和证据；主 agent 统一集成 |
| 用户输入工具 | 确认画风、保留哪张脸、是否使用专用超分，以及本地提交/许可/素材范围 | 当前宿主的问答界面，或普通对话 | 用户明确回答；等待时间不等于同意，已有决定不反复询问 |
| 结果展示：`open_in_codex` | 打开生成的网页或工作区文档，方便用户查看 | IDE 文件/预览面板、浏览器链接、可访问的本地文件链接 | 被打开的实际文件或 URL；打开成功不等于验收成功 |
| Skill 阅读 / `skill-creator` | 读取上游 Live2D skill、组织可复用 `SKILL.md`，并检查 skill 格式 | 当前宿主的文件/资源阅读器；人工核对 skill frontmatter 和流程 | 实际读过的 skill 位置与用途；不能将文档中的指令当作用户新授权 |

Shell、图片理解、图像生成、浏览器和协作是不同能力。宿主能够执行 Python 不代表能生成图片；
能够生成立绘不代表有 Cubism 编码器；浏览器能打开网页也不证明 `.moc3` 已被 Core 加载。

## 按能力选择入口

| 当前可用条件 | 可以先完成什么 | 暂时不能证明什么 |
| --- | --- | --- |
| 只有本地文件与 Python | [manifest / runtime 结构检查](commands.md#检查配方与运行资源)、kit 测试与资料整理 | MOC 原生有效性、可见动作、画稿质量 |
| 加上 JDK 21、Git 和引擎构建依赖 | [生成通用最小示例并导出](commands.md#验证最小导出链) | 官方 Core 验收和目标软件验收 |
| 有本机 Java/native Core | [原生参数与几何检查](commands.md#检查官方-core-与几何) | 所有渲染器的接缝表现、绘画审美 |
| 有 Web Core、WebGL 与预览依赖 | [真实网页预览](commands.md#准备与检查真实网页预览)；合成面捕/半身输入 | 摄像头面捕、外部设备接入、用户 VTS 验收 |
| 有兼容 GPU、NCNN CLI 和动漫权重 | [专用动漫超分](commands.md#完成低分修复后再超分) | 自动修好错位、发束语义、错误图层归属 |
| 有用户本机 VTube Studio | 用户导入运行包并执行最终验收 | 自动继承前一版或别人机器的验收结果 |

## 本次未建立的能力

- **没有接入真实摄像头、麦克风或 Mocopi 设备。** 网页使用合成输入，端口服务还禁止摄像头和麦克风请求。
- **CubismExternalEditMCP 没有成功连接并完成最终模型编辑。** 它作为可选路线保留在 [MCP 指引](../mcp/README.md)，不列为生产主线的已验证编辑器。
- **psd2live 内置 MCP 不是本 kit 批量产出的必需路径。** 已复现的主线是 Kotlin manifest 适配和实际导出器。
- 原会话未用到的第三方 connector、语音专用屏幕上下文工具，不因宿主工具列表中出现过就算作本 kit 用过的工具。

## 把工作流交给另一个 agent

给新 agent 仓库地址、自己的参考图、希望保留的批准稿，以及可用的本地依赖位置。
让它从 [SKILL.md](../SKILL.md) 和 [环境检查](../docs/setup.md) 开始，用最小示例证明导出链，
再处理自己的角色。不要复制原会话的标签 ID、机器路径、秘密配置或历史验收结论。

没有 `skill-creator` 时仍可阅读并使用本仓库 skill；它是这次编写 kit 时的辅助能力，
不是 Live2D 模型运行依赖。需要了解软件本身、版本和许可时，查 [工具地图](../docs/tooling.md)、
[第三方说明](../THIRD_PARTY_NOTICES.md) 与 [任务命令速查](commands.md)。
