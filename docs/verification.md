## 实际执行的链路

| 检查 | 结果与范围 |
| --- | --- |
| 固定引擎 | 获取 pin，应用累计补丁，核对 8 个修改文件 SHA；首次构建与再次 setup 均通过 |
| 原创最小素材 | Java 21 生成 14 层，逻辑画布 512×768，低分图集 1024×1024 |
| 导出 | 生成真正的 PSD、CMO3、MOC3、PNG 图集、物理与动作文件；导出任务成功 |
| PSD 提取 | 重新提取生成的 PSD，得到 14 个可见栅格层及位置；manifest 结构检查通过 |
| 官方 native Core | Core 6.0.257，MOC version 5，一致性通过；192 个取样姿态，其中 125 个嘴形/张嘴/头身眼组合，未发现无效顶点值或透明度范围错误 |
| 专用动漫超分 | 本机 Upscayl NCNN + `realesr-animevideov3-x4`，RGB 神经 4×、alpha 独立 bicubic；1024×1024 → 4096×4096 RGBA |
| 高清再导出 | 低分与高清 MOC3 **逐字节一致**；高清包再次通过 native Core 与资源检查 |
| 真实 Web Core | 最终高清包通过 22 项浏览器检查；Web Core **5.1.0**，WebGL 最大纹理 8192、实际遮罩 1024；播放、暂停、手调、复位和合成输入驱动实际 Core |
| 浏览器输入身份 | 监听页面真正载入的 model3、MOC、4096 图集响应字节，SHA 全部匹配准备清单；错误 SHA 与缺失 MOC 清单记录两个反例均正确失败 |
| 旧超分拒绝 | 故意给新配方错误的来源 SHA，真实导出任务拒绝注入，退出码 1 |
| 超尺寸拒绝 | 4096 源页的 4× 输出超过默认 8192 上限，推理前拒绝，未创建输出目录 |
| 运行包 | 复制 9 个引用文件与发布元数据；ZIP 内容完整，无源代码/SDK/权重混入 |
| Kit 检查 | 17 项 Python 测试通过；Python、Shell、浏览器模块语法检查通过；skill-creator 的 quick_validate 通过 |

本最小示例有 19 个参数、16 个 Drawable、2996 个顶点、3638 个三角形。
`ParamBrowLY` / `ParamBrowRY` 没有测得独立可见绑定；不要将两个槽位算作眉毛追踪。
Core 报告保留三角形退化/翻转与嘴部透明度；闭合或隐藏几何的记录需结合 alpha、
遮罩和真实画面判断，没有套用原角色专用的嘴层淡入公式来判定所有模型。
这不是成品美术质量或 VTube Studio 验收记录，也没有在官方 Editor 中人工验收 CMO。
默认与模拟暂停帧已目视检查；摄像头请求为 0，浏览器异常为 0。
Web Core 和 native Core 是不同版本的本地组件，分别记录，不能混写版本号。
