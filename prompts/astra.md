# 长任务启动提示

案例使用配置：**GPT-6 Astra / Ultra reasoning**。在宿主支持时可由用户选择；
下面的提示不会改变模型、获得额度或安装工具，其他有文件/代码能力的 agent 也可以使用。

把下面一段作为任务提示，附上自己的图片与需求：

> 使用 `$live2d-agent-kit`，先阅读此仓库 `SKILL.md`。
> 我的目标是把附件角色制作成能在 VTube Studio 使用的 Live2D 模型，并提供网页动作预览。
> 先区分参考图、设定图和我真正的要求，检查可用环境，运行通用最小示例验证真实导出。
> 再确定本角色正面母图、服装、画风、保留的脸、活动范围与交付范围。
>
> 如果只有平面图片，先列出需要保留、切分和补画的部分；按原图坐标定位。
> 我确认的脸不要反复重画。不要把假 MOC、静态立绘或仅能摆动的网页图片当作完成的 Live2D。
> 遇到接缝先检查图层中的可见像素和运动归属，尤其眼角、嘴周肤色、发根、发尖与背带。
> 先修原分辨率结构，再用合适的专用动漫工具超分；保持逻辑坐标和 UV，检查 alpha 与纹理哈希。
>
> 在独立输出目录持续推进。可把互不冲突的素材检查、工具核实与视觉复查交给子 agent，
> 一个负责人顺序处理共享导出与同一 GPU 推理。定期告诉我关键发现、已修内容与剩余不确定项。
> 不要重复询问已有授权；需要我决定的关键冲突尽早提出，并继续不依赖答案的工作。
>
> 用实际 Cubism Core 和网页运行时检查，保留参数组合、截图、版本与 SHA。
> 最后给我 runtime 包、可编辑源工程、网页预览、复建步骤和简短的已验证/未验证说明。
> 未经我明确要求不要公开图片、推送代码、访问摄像头或替我给别人发消息。

恢复长任务时，另附：当前批准母图、最新 manifest、最后导出目录、正在运行的端口、
MOC/图集 SHA、已通过的检查和未完成的缺陷；不要只给“继续”而丢失状态。
